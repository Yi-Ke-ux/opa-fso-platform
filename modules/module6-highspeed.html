一、高速扫描的瓶颈与思路

OPA 波束转向速度受两方面制约：①相位器响应（热光为 ms 级，速度慢）；②控制电子把相位配置下发到各通道的时间（串行 DAC、通信开销）。文献采用反偏 p-n 结电光移相器（载流子色散，μs 级），并设计 FPGA + 双端口 RAM + 多通道并行 DAC 的高速控制架构，把单帧相位配置压缩到 5 μs 以内。

二、电光移相原理

反偏 p-n 结改变耗尽区载流子浓度，经等离子色散（载流子色散）效应改变折射率 Δn，长度 L 的移相器产生相位：

电光相位（式1）
$$\varphi=\frac{2\pi\,\Delta n\,L}{\lambda}$$
2π 移相长度（式2）
$$L_{2\pi}=\frac{\lambda}{\Delta n}$$

取 Δn≈1×10⁻⁴、λ=1550 nm，则 L₂π≈15.5 mm；增大 Δn 可缩短移相器。电光效应仅受载流子寿命/RC 限制，达 μs 甚至 ns 级，远快于热光（~200 ms 量级的温度稳定）。

三、二维扫描解耦

  • 横向 θx：阵元相位差控制，$\sin\theta_x=\lambda\varphi/(2\pi d)$；
  • 纵向 θy：波长经光栅控制，$\sin\theta_y=n_{\mathrm{eff}}-\lambda/p$。

纵向用 5 个波长 1542.1 / 1545.3 / 1548.5 / 1551.7 / 1554.9 nm，波长间隔 0.07 nm 对应纵向步进约 0.225°。

四、FPGA 控制架构

控制电子以 FPGA 为核心（图1）：

  • 双端口 RAM（D_RAM）：存储 M×N（M=128 通道、N 个扫描角）的相位查找表，一端由逻辑写入、另一端并行读出，实现“查表即输出”；
  • DAC：LTC2664-12，12 bit、输出 ±10 V、分辨率 4.88 mV/LSB，多路并行把相位码转成驱动电压；
  • SPI Flash：掉电保存相位表/校准数据，上电加载；
  • FPGA 按时序从 RAM 读出 128 通道相位码，经 DAC 同时建立。

五、相位配置时序与扫描帧

单步横向配置时间 τx（式6）由 RAM 读取、SPI/总线传输、DAC 建立时间组成；整帧 128 通道配置 < 5 μs。一个 5×5 扫描帧：横向每行连续 15 点、行间纵向切换 1 次，共 5 行：

5×5 帧时间（式5）
$$t=(15\,\tau_x+\tau_y)\times 5$$

τy 为波长切换（激光器调谐）时间。该并行查表 + 并行 DAC 架构避免逐通道串行下发，是高速的关键。

六、SPGD 校准与余弦相似度

用 SPGD（随机并行梯度下降）对 128 通道相位做无模型校准，以余弦相似度衡量实测方向图与目标方向图的吻合程度，迭代使相似度趋近 1；校准结果固化进 RAM 查找表。

结论：电光 p-n 移相（μs）+ FPGA 双端口 RAM 并行查表 + 多通道 DAC，使 128 通道 2D OPA 单帧配置 < 5 μs，较热光方案（ms 级）提速约 4 个数量级，可支撑高速光束扫描、快速捕获跟踪与高帧率 LiDAR/FSO。

模块 6 使用说明

本模块含 2D 光斑、横向方向图、Table II、FPGA 时序、5×5 扫描帧、SPGD、速度对比 7 组仿真。

① 2D 远场光斑

  1. 选 N（默认 128）、d；
  2. 调横向角 θx（相位，±15°）与纵向波长（1542.1–1554.9 nm）；
  3. 光斑随之在二维平面移动；读数给出 L₂π（式2）、纵向角 θy、配置时间。
启动连续 2D 扫描：光斑自动按扫描帧遍历二维角度区，直观呈现高速扫描。

② 横向方向图 / ③ Table II

  • 横向方向图显示主瓣随 θx 移动；
  • Table II 卡呈现 −0.6~+0.6°（0.1 间隔）的 FWHM（≈0.30–0.33°）与 SLSR（≈7–10 dB）。

④ FPGA 时序 / ⑤ 5×5 扫描帧

  • 时序图展示 RAM 读取 → 总线传输 → DAC 建立的过程，整帧 < 5 μs；
  • 5×5 网格动画逐点点亮（每行 15 点横向 + 1 次纵向切换），帧时间按式5 估算。

⑥ SPGD / ⑦ 速度对比

  • SPGD 余弦相似度随迭代趋近 1；
  • 柱状（对数轴）对比电光（~5 μs）与热光（~2×10⁵ μs）配置时间，相差约 4 个数量级。
