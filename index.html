平台特点与技术栈

零安装、零后端，所有物理计算在浏览器本地实时完成。

真实物理内核

基于相控阵阵列因子、光栅方程、高斯光束传播与高斯噪声通信链路逐项数值求解，参数与公式均来自文献，结果可复现、可追溯。

实时交互仿真

拖动滑块即刻重算方向图、光斑与链路曲线；算法类模块支持单步 / 自动迭代，直观呈现收敛与扫描过程。

理论 + 实操闭环

每个模块配套 KaTeX 排版公式、参数表、分步使用说明与预期结果，先看理论再动手，适合教学与项目答辩演示。

动态三维 · 8 种通信场景 NEW

Three.js 构建：5 类基础场景（直接协同 / 自由空间 / 有限空间 / 密集障碍 / 自动 Mesh 寻路）外加 3 个「指令驱动链式中继」场景（2 / 3 / 4 台 OPA 的两至四跳接力）。光束实时遮挡检测、遇障变红断链；中继场景按指令把信号经唯一可达的中继逐跳转发终端，实时显示距离 / 功率 / BER / 大气衰减，参数全部可调。

技术栈：原生 HTML5 + CSS3 + JavaScript（无框架、无构建）· ECharts 5（曲线/图表）· Canvas 2D（光斑/热图/眼图）· Three.js r128（动态三维场景 / 光束遮挡）· KaTeX（公式）· VS Code + Live Server 本地运行。

三步快速开始

用 VS Code 打开项目文件夹

将整个 opa-fso-platform 文件夹拖入 VS Code，安装推荐的「Live Server」扩展。

启动本地服务器

在 index.html 上右键选择「Open with Live Server」，或在终端运行 python -m http.server 8000 后访问 http://localhost:8000。

选择模块开始仿真

在首页点击任一模块卡片，默认进入「交互仿真」标签，调节左侧参数、点击运行即可；另两个标签提供理论分析与使用说明。
