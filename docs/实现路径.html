一、总体架构

平台为纯静态、多文件、无构建的前端项目：不用 React/Vue、不用打包器、无后端与数据库。所有物理计算在浏览器本地完成。技术选型：

  • ECharts 5.5.0：方向图、收敛曲线、BER、时序、柱状等所有二维坐标图；
  • Canvas 2D：光斑、热图、眼图、扫描帧动画；
  • KaTeX 0.16.11：理论公式排版（$...$、$$...$$）；
  • 三者均经 jsDelivr CDN 引入，字体经自托管镜像，无需本地依赖。

四、公共物理引擎 common.js

通过 const P = window.OPA; 使用，函数分组如下：

分组函数
常量/基础D2R, R2D, C0, sinc, erfc, qfunc, dbA, dbP
一维相控阵linearPhases, arrayFactor1D, steeredPattern, steerToDphi, dphiToSteer
波束宽度/视场fovEdge, hpbwUniform, nullToNull
光栅天线gratingAngle, gratingAngleV2, gratingPeriod
高斯光束gaussDivergence, gaussIntensity
方向图分析analyzePattern（peakAng / fwhm / pslr）
通信链路berFromPower, powerSweep, eyeTrace, gaussRand
二维阵列arrayFactor2D
ECharts 封装makeChart, patternSeries
CanvasheatColor, renderHeatmap, clearCanvas, drawGaussianSpot, fitCanvas
UI 工具setupTabs, bindSlider, setSliderText, logTo, clearLog, sleep, renderMath

单位约定（重要）

  • arrayFactor1D / steeredPattern / linearPhases 中 d 与 lambda 必须同单位，脚本统一转成米（μm×1e-6、nm×1e-9）；
  • 角度对外用度，函数内部用 D2R 转弧度；
  • arrayFactor1D 返回 psi 已除以 N（主瓣≈1），db 为相对峰值归一化；
  • drawGaussianSpot(canvas, cx, cy, r, 'r,g,b', alpha) 的 cx/cy 为 0~1 归一化坐标。

六、页面生命周期 / 数据流

  1. 加载：CDN 脚本与 common.js 就绪；
  2. 初始化：内联 IIFE 中 makeChart 建图、读取控件初值、调用各 draw* 首次渲染；
  3. 交互：滑块 input / 按钮 click → 读取参数 → 物理函数计算 → setOption / Canvas 重绘 → 更新读数；
  4. 异步：训练/动画用 async/await + sleep 分片，避免阻塞主线程；
  5. 切 tab：setupTabs 切换 pane 并触发 resize 让 ECharts 重新适配。

七、如何新增一个模块（扩展指南）

  1. 复制任一 moduleN-*.html 为 module7-xxx.html；
  2. 修改标题、文献信息、标签，把导航中 active 状态移到新页（并在 index.html 增加卡片、topbar 增加入口）；
  3. 在“交互仿真”里放置控件（给滑块唯一 id）与图表容器（div.chart-box / canvas）；
  4. 在内联 <script> 中：const P=window.OPA; 建图、写 draw 函数、addEventListener 绑定、末尾调用 setupTabs() 与首次渲染；
  5. 通用物理优先复用 common.js；专属算法写在模块内联脚本里；
  6. 按第九节做验证。
约定：所有按钮必须绑定真实 handler（禁止僵尸按钮）；所有 id 全局唯一；文件名语义化。

八、如何修改参数 / 样式

  • 默认参数：改各模块 HTML 控件的 value/min/max；
  • 配色/字体/间距：集中在 style.css 顶部的 CSS 变量（:root）；
  • 物理常数/标定：如 BER 灵敏度斜率在 common.js berFromPower；
  • 新增公共函数：写在 common.js 并加入末尾 global.OPA={...} 导出列表。

九、本地验证方法

  1. 语法检查：把页面内联脚本抽出后用 node --check（平台根目录提供 extract_check.py：python ../extract_check.py 模块.html）；
  2. 页面自检：用 html skill 的 shot.py 生成桌面/移动截图，核对 consoleErrors 与渲染；
  3. 手动核对：Live Server 打开，F12 看 Console 无报错，拖动每个控件确认图表响应；
  4. 数值核对：典型值（如 16 阵元 d=3μm 指向 8°：peakAng=8.00、HPBW=1.66°、PSLR=13.15 dB）。

十、部署建议

  • 平台为纯静态，可直接放到任意静态服务器 / GitHub Pages / Gitee Pages / 校园网静态空间；
  • 保持相对路径与目录结构，无需后端；
  • 如需完全离线，可把 ECharts/KaTeX/字体下载到 assets 并改为本地引用。
设计要点回顾：“公共物理引擎下沉 common.js + 模块差异内联 + 统一三标签结构”，使平台既能保证物理一致性，又便于逐模块复现与后续扩展。
